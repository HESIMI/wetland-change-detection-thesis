# 主模型筛选说明

更新时间：`2026-05-13`

## 1. 筛选原则

本课题的主模型选择以实验结果和工程可实现性为依据，不预设固定技术路线。筛选原则主要包括：

1. 适配高分辨率双时相遥感输入
2. 能够兼顾精度、效率与显存开销
3. 对湿地伪变化具备可扩展的抑制机制
4. 具备公开代码或稳定复现基础
5. 支持后续消融实验与结构扩展

## 2. 主干筛选范围

当前纳入主干筛选范围的模型包括：

- `ChangeMamba`
- `CDMamba`
- `CD-Lamba`
- `M-CD`
- `ChangeViT`
- `STeInFormer`

这些模型覆盖了两类主要方案：

- 状态空间建模主干
- Transformer / ViT 主干

## 3. 语义模块筛选范围

当前纳入语义增强比较范围的模型或思想包括：

- `ChangeCLIP`
- `LSC-CD`
- `TextSCD`
- `Semantic-CD`
- `RemoteCLIP`
- `GeoRSCLIP`

其中，`ChangeCLIP` 更适合作为视觉-文本对齐设计参考，`RemoteCLIP` 与 `GeoRSCLIP` 更适合作为遥感领域文本编码器来源。

## 4. 解码头与边界增强范围

当前纳入重点关注的对象级或边界增强路线包括：

- `MaskCD`
- `SARAS-Net`

这类方法更适合处理湿地边界复杂、斑块破碎的场景，对主干固定后的结构增强具有参考价值。

## 5. 基础模型适配范围

作为补充路线，纳入考察的基础模型适配方法包括：

- `BAN`
- `RoCD`
- `AdaptVFMs-RSCD`
- `FMT`
- `Changen2`

该路线主要服务于泛化能力、迁移学习和后续扩展问题，当前阶段不作为第一轮主模型的核心比较对象。

## 6. 当前筛选框架

主模型筛选按照以下层次展开：

### 第一层：主干比较

重点比较：

- `ChangeMamba`
- `CDMamba`
- `CD-Lamba`
- `ChangeViT`
- `STeInFormer`

评价指标包括：

- `F1-score`
- `IoU`
- 推理速度
- 显存占用
- 对复杂边界、小斑块和伪变化区域的可视化表现

### 第二层：语义增强比较

在主干模型基础上进一步比较：

- 是否引入视觉-文本语义先验
- 是否采用固定 prompt
- 是否采用可学习 prompt
- 是否引入文本对齐损失

### 第三层：边界与对象级增强比较

在精度与误检控制基础上，比较：

- 是否需要更强解码头
- 是否需要对象级 mask 表达
- 是否需要边界一致性增强

## 7. 当前阶段结论

从当前调研与已有实验基础出发，主模型候选可以归纳为三类：

### A. 高效主干路线

- `ChangeMamba`
- `CDMamba`
- `CD-Lamba`

该路线的优势在于效率与长程建模能力，适合高分辨率双时相输入。

### B. 强 Transformer 路线

- `ChangeViT`
- `STeInFormer`

该路线适合作为非 Mamba 主干候选，用于检验状态空间模型与 Transformer 在本任务中的差异。

### C. 语义与边界增强路线

- `ChangeCLIP`
- `MaskCD`

其中，`ChangeCLIP` 用于语义先验建模，`MaskCD` 用于边界和对象级增强。

## 8. 当前阶段任务定位

当前阶段的任务不是确定单一模型名称，而是建立完整的主模型筛选框架，并在可复现模型范围内形成可比较的实验体系。
