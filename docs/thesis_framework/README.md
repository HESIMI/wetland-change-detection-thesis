# 论文框架与技术路线

## 1. 论文目标

论文聚焦于湿地变化检测中的三个核心问题：

1. 高分辨率遥感影像下的计算效率瓶颈
2. 湿地场景中季节性与水位波动导致的伪变化干扰
3. 细碎湿地斑块与复杂边界的保持能力不足

因此，论文不预设单一模型，而是通过文献调研与实验比较确定：

- 精度更高
- 泛化更强
- 误检更低
- 工程实现可控

的最终技术方案。

### 第三章 模型设计

本章为论文核心，当前阶段保留以下候选方向：

- `ChangeMamba / CDMamba / CD-Lamba`
- `ChangeViT / STeInFormer`
- `MaskCD`
- `ChangeCLIP` 或轻量语义引导模块

模型设计可围绕以下几类结构展开：

1. **高效主干 + 轻量语义引导**
2. **强 Transformer 主干 + 语义增强**
3. **Mamba 主干 + 对象级解码**
4. **主干筛选后再做融合结构**

## 3. 模型筛选框架

当前模型筛选按照以下顺序推进：

1. 先筛主干
   - `ChangeMamba`
   - `CDMamba`
   - `CD-Lamba`
   - `ChangeViT`
   - `STeInFormer`

2. 再筛语义增强
   - `ChangeCLIP`
   - `LSC-CD`
   - `TextSCD`
   - `Semantic-CD`

3. 再判断是否需要更强解码头
   - `MaskCD`

## 4. 备选技术路线

### 路线 A

`Mamba` 或 `Transformer` 高效主干  
+ 轻量文本语义引导  
+ 面向湿地伪变化抑制的对齐约束

### 路线 B

`Mamba / Transformer` 主干  
+ `MaskCD` 风格解码头  
+ 小斑块与边界增强

## 5. 当前框架结论

当前阶段的重点在于建立可比较的模型筛选框架，并据此形成适用于湿地变化检测任务的数据-模型-语义组合方案。
