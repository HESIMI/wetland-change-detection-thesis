## 2. 当前 baseline 结果

当前已完成 `Siamese UNet` 基线实验，最正式结果来自：

- `Weighted BCE + Dice`
- `20 epoch`
- 本地 GPU 调试完成

关键指标：

| 指标 | 数值 |
| --- | ---: |
| Train F1 | `0.239` |
| Train IoU | `0.149` |
| Val F1 | `0.054` |
| Val IoU | `0.030` |
| Test F1 | `0.257` |
| Test IoU | `0.162` |

### 当前解读

- baseline 已经说明数据链路和训练链路可用
- 传统 CNN 在湿地复杂场景下仍有明显局限
- 这为后续引入更强 backbone 或语义引导提供了依据
