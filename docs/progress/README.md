## 2. Baseline 实验结果

当前已完成 `Siamese UNet` 基线实验，主要结果来自以下训练设置：

- `Weighted BCE + Dice`
- `20 epoch`
- 本地 GPU 调试完成

关键指标：

| 指标 | 数值 |
| --- | ---: |
| Train F1 | `0.239` |
| Train IoU | `0.149` |
| Val F1 | `0.054` |
| Val IoU | `0.030` |
| Test F1 | `0.257` |
| Test IoU | `0.162` |

### 结果说明

- 现有结果表明数据链路与训练链路已经打通
- 传统 CNN 方法在湿地复杂场景下仍存在性能上限
- 后续工作将围绕更强主干与语义增强机制展开
